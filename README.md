# Ohlala Apps

A curated collection of web applications and native Android tools crafted with precision, minimalist aesthetics, and local-first privacy.

🌐 **Live Website**: [https://aiohlala.github.io/apps/](https://aiohlala.github.io/apps/)

## Featured Applications
1. **PureScan QR**: Ultra-fast, ad-free QR Code scanner built with Jetpack Compose & Google ML Kit.
2. **FineVolume**: Advanced volume controller breaking hardware volume step limits with dual boost engine.
3. **AI Imaging Studio**: Local-first background removal and watermark eraser powered by Google MediaPipe WASM.
4. **Send2Me**: Cross-platform peer-to-peer file & text transfer with zero server logging.
5. **Watermark Remover**: Instant client-side OpenCV inpainting tool.
6. **Meow Battle**: Multiplayer live action cat arena game.
